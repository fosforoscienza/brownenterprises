2. What cookies are

Cookies are small text files that visited websites send to the user's device, where they are stored to be sent back to the same sites on the next visit. Similar technologies (such as localStorage) allow information to be stored on the device for comparable purposes.

3. Types of cookies used by this website

3.1 Technical and functionality cookies (always active)

These tools are necessary for the website to work correctly and to store user preferences; they do not require consent. Among these, the site uses a value stored in the browser localStorage to remember the choice made on the cookie banner.

The website uses Google Analytics 4 (provider: Google Ireland Limited), loaded via gtag.js, to collect aggregated statistical information about the use of the site (pages visited, visit duration, device type). These cookies are installed only after the user has given consent through the banner. Without consent, analytics storage remains disabled (Google Consent Mode v2, default setting "denied").

4. Managing consent

On the first visit a banner is displayed allowing the user to accept or reject analytics cookies. The user may change this choice at any time by clearing the site data from their browser, or manage and disable cookies through the browser settings:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Apple Safari

It is also possible to disable Google Analytics by installing the opt-out browser add-on provided by Google.
